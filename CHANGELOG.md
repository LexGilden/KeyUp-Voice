# Changelog

All notable user-facing changes are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.5.0] - 2026-07-31

- Added configurable keyboard combinations and mouse side buttons for both
  push-to-talk actions.
- Added `Esc` cancellation for an active recording.
- Added undo for the latest insertion.
- Added model disk-usage reporting and removal of unused or incomplete models.

## [1.4.1] - 2026-07-31

- Changed the default dictation hotkey to Right Alt.
- Prepared the project for public GitHub distribution.
- Expanded the About dialog and project documentation.
- Added repository hygiene, contribution, security, privacy, and CI files.
- Made the Python setup script portable across user accounts.

## [1.4.0] - 2026-07-31

- Added selectable Tiny, Base, Small, Medium, and Large-v3 Whisper models.
- Added verified on-demand downloads and switching between installed models.

## [1.3.0] - 2026-07-31

- Added Russian and English application interfaces.
- Added a mandatory installer language selector.

## [1.2.0] - 2026-07-31

- Renamed the application from Golos to KeyUp Voice.
- Migrated settings, shortcuts, startup entries, and executable branding.

## [1.1.2] - 2026-07-30

- Fixed a Windows issue that could create the settings dialog in a hidden state.

## [1.1.1] - 2026-07-30

- Removed the technical “Open settings folder” tray menu item.

## [1.1.0] - 2026-07-30

- Added the thin installer and first-run component downloader.
- Added NVIDIA detection, CUDA downloads, CPU fallback, and verified downloads.
- Added Whisper translation to English with a separate hotkey.
- Added model and CUDA cleanup during uninstall.
