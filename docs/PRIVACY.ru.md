# Конфиденциальность

KeyUp Voice предназначен для локального распознавания речи.

## Звук

- Микрофон записывается только во время удержания назначенной клавиши.
- Звуковые данные находятся в памяти процесса только для текущего запроса.
- Запись передаётся локально загруженной модели Whisper.
- После распознавания звук удаляется и не сохраняется в аудиофайл.

## Текст и буфер обмена

Распознанный текст временно помещается в буфер обмена Windows для вставки через
`Ctrl+V`. KeyUp Voice копирует предыдущее содержимое буфера и восстанавливает
его через небольшую задержку.

## Сетевые подключения

Интернет используется только при отсутствии необходимых компонентов:

- модели Whisper загружаются с Hugging Face;
- на совместимых NVIDIA пакеты cuBLAS и cuDNN загружаются с PyPI.

Размеры и SHA-256 загруженных файлов проверяются. После настройки распознавание
и перевод не требуют интернета.

## Журнал

Технический журнал хранится здесь:

```text
%APPDATA%\KeyUp Voice\keyup-voice.log
```

Он содержит состояния программы, сведения об устройстве и режиме обработки,
ошибки, длительность и количество символов. Записанный звук и распознанный текст
не должны попадать в журнал. Перед публикацией журнала проверьте его содержимое.

## Телеметрия

В KeyUp Voice нет аналитики, рекламы, учётных записей и телеметрии.
